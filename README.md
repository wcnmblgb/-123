# 🐍 贪吃蛇 · Snake

一个用 **Python 标准库**写成的贪吃蛇小游戏，提供三种玩法：**图形界面（tkinter）**、**终端（curses）**和无界面的 **AI 自动演示**。

零第三方依赖 —— 克隆下来就能玩（终端版在 Windows 上需要一个可选的补丁包，见下文）。

## 快速开始

需要 **Python 3.10+**（用到 `X | None` 这类联合类型标注，它在 3.10 才可用于运行时求值；
CI 已在 3.10 / 3.11 / 3.12 / 3.13 上验证）。

```bash
# 1. 图形界面版（默认，直接玩）
python main.py

# 2. 终端版
python main.py terminal

# 3. 无界面：让 AI 自己玩给你看
python main.py demo
```

不需要 `pip install` 任何东西。tkinter 是 Python 自带的。

## 游戏规则

| 项目 | 规则 |
|---|---|
| 初始蛇长 | 3 格，位于棋盘中央，朝右 |
| 吃食物 | **+10 × 当前等级** 分，蛇身长 1 格 |
| 升级 | 每吃 5 个食物升 1 级，最高 10 级，速度随之加快 |
| 死亡 | 撞墙（默认）或咬到自己 |
| 穿墙模式 | 加 `--wrap` 参数后从另一侧出现，不会撞死 |
| 通关 | 蛇填满整个棋盘 |

**两个容易踩的细节**（都已处理）：

* **不能原地掉头**：向右走时按左会被忽略，这是必死操作；
* **可以走进尾巴那一格**：因为尾巴在同一帧会让开，这不算自撞。

## 常用参数

```bash
python main.py --width 30 --height 20     # 改棋盘大小
python main.py --speed 10 --max-speed 25  # 改初始 / 满级速度（格每秒）
python main.py --wrap                     # 穿墙模式
python main.py --seed 42                  # 固定随机种子，食物序列可复现
python main.py --start-length 5           # 初始蛇长
python main.py demo --no-realtime         # AI 快速跑完，只打印结果
python main.py selftest                   # 跑一遍单元测试
python main.py --help                     # 查看全部参数
```

```
│   ├── gui.py           # tkinter 图形界面
│   ├── terminal.py      # curses 终端界面（curses 缺失时优雅降级）
│   └── headless.py      # 无界面：AI 演示 + ASCII 棋盘渲染
└── .github/workflows/tests.yml   # CI：每次提交自动跑测试
```

### 为什么把逻辑单独放在 `core.py`

`core.py` 不认识 tkinter 和 curses，它只负责「时间前进一格会发生什么」：

```python
from snake.core import SnakeGame, Direction

game = SnakeGame(seed=42)
game.turn(Direction.DOWN)
result = game.step()

print(game.score, game.length, game.head)
if result.ate_food:
    print("吃到食物了")
```

这样带来两个好处：

1. **可以测试** —— 48 个测试全部在无显示器、无网络的环境下跑完，4 秒出结果；
2. **可以复现** —— 用 `seed` 固定随机数，同一个种子永远得到同一串食物位置，出问题能精确重放。

## AI 是怎么想的

`demo` 模式里的 AI 只用了两条规则，但足够撑到棋盘快满：

1. **有路就走** —— 用 BFS 求到食物的最短路，走第一步。比「哪一步离食物更近就走哪步」可靠得多：贪心距离会让蛇贴着自己的身体绕圈，永远走不到食物跟前。
2. **没路就活** —— 到食物的路被自己的身体挡住时（BFS 返回空），改选「走完之后剩余活动空间最大」的方向，等身体挪开、路重新打开。

实力参考（默认 24×20 棋盘）：

| 棋盘 | 吃到的食物 | 得分 | 走的帧数 |
|---|---|---|---|
| 15×12 | 33 | 1260 | 373 |
| 20×16 | 56 ~ 68 | 3350 ~ 4550 | 825 ~ 1087 |
| 24×20 | 85 | 6250 | 1794 |
| 30×20 | 71 | 4850 | 1376 |

> 开发过程中记录一个真实的坑：最初版本的 AI 在吃到**第一个**食物后就绕着圈再也不吃了，分数永远停在 10 分。原因是最初的排序规则把「追尾安全」放在了「离食物更近」前面，导致蛇为了安全永远放弃食物。修复后才有上表的表现。

## 终端版说明

终端版基于 `curses`，而 **Windows 上的标准 Python 不带 `curses`**（本机实测 `ModuleNotFoundError: No module named '_curses'`）。需要的话装一个补丁包：

```bash
pip install windows-curses
```

没有安装也**不会报错崩溃** —— 程序会打印一条提示并告诉你改用 `gui` 或 `demo` 模式。
